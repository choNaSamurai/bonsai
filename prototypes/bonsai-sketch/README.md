# Bonsai sketch — visual reference (PA-102X, PA-109)

A standalone WebGL2 page (JS + GLSL, no dependencies) that is the owner-approved **visual reference** for how trees look and grow in Pocket Arbor. It is not game code: the Unity game ports its models (ADR-0011 B*, `docs/architecture/TRUNK_REALISM.md`).

- `sketch_v40.html` — the current version (2026-10-17): Shimpaku juniper + Japanese maple (ficus is "coming soon"; Kuromatsu and Yamazakura are hidden behind `LEGACY_SP=false`). Self-contained: textures are embedded as WebP data URIs (~1 MB).
- `textures/juniper/` — original texture sources generated by the owner in Nano Banana; `textures/PROMPTS.md` — the exact prompts and what is used.
- `REFERENCES.md` — sources and licences of the reference photos (the photos themselves are not committed).

## Running
A ~1 MB page does not open via `file://` in the app's browser pane — serve it locally:
```bash
cd prototypes/bonsai-sketch && python3 -m http.server 8790 --bind 127.0.0.1
```
then open `http://127.0.0.1:8790/sketch_v40.html`.

## What is inside (v40)
Time machine (6 years from seedling, deterministic from seed + cut events), pruning shears with species regrowth, ageing, seasons and weather, quality tiers (leaf elements 30k/15k/8k, twigs 20k/12k/7k), traditional pots by species × style, juniper sculpted trunk (lobed section, ropes, split with one gap, live veins, moss, generated wood textures) with procedural scale-leaf foliage, maple dome canopy with leaf light. Design decisions are marked in code as `// vNN decision:`.
