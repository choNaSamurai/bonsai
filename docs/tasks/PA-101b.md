## User story
Як власник, я хочу, щоб «безкоштовні» налаштування розміру були в репо, а стек пакетів — без зайвих залежностей, щоб білд вкладався в переглянуті бюджети з запасом під контент.

## Рішення власника (2026-10-05, варіант C)
- Бюджети: Android Play download arm64 **≤ 28 МБ** (жорстка межа **30**); iOS App Store download **≤ 45 МБ**, install **≤ 60 МБ**. Переглядаються після вертикального зрізу, якщо контент вимагатиме.
- Безкоштовні налаштування: IL2CPP Code Generation OptimizeSize, C++ Release, R8 (`minifyRelease`), URP strip post-processing + 2D variants, звужений `link.xml`, Unity-сплеш вимкнено (Unity 6 дозволяє на Personal).
- Прибрати `com.unity.localization` (+ Addressables) → власні таблиці рядків (ADR-0006, UI_IMPLEMENTATION §6).
- Прибрати пряму залежність `com.unity.nuget.newtonsoft-json` → збереження на `JsonUtility` (ADR-0008 rev.3). Транзитивно Newtonsoft лишається через Unity IAP 5 — очікувано.
- Unity IAP 5 лишається; власний білінг-плагін — опція v1.1 (ADR-0009).
- Vulkan + GLES3 лишаються.
