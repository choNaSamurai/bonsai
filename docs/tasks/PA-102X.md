## User story
Як гравець, я хочу бачити бонсай, що природно росте від саджанця до зрілого дерева, з правильною формою стилю, виразним Небарі, гілками ярусами й листям своєї породи, щоб дерево виглядало як справжнє і реагувало на мій догляд.

## Що вже є в ескізі (еталон, 2026-10-08)
- Стовбур одним тілом із коренями: вигини за правилами стилю (Мойоґі / Чоккан / Шакан), конусність, верхівка над основою, Небарі з ребрами-підпорами.
- Гілки: перша на ~30% висоти, кроки ×0.8, кожна третя — задня, бічні на зовнішньому боці вигинів, ≤ ⅓ товщини стовбура, 3 рівні розгалуження, купол верхівки.
- Листя за породою: Момідзі (пальчасті), Ямадзакура (яйцеподібні, звислі, бронзові молоді), Куромацу (пучки хвої); подушки з листя, напівпрозора тінь крони.
- Згенерований горщик за породою (токонаме / куро / селадон), процедурна кора з рельєфом, ґрунт із мохом.
- Ріст від саджанця до зрілого (параметр t ∈ [0, 1]), детермінований від насіння.

Числа зчитано з коду `sketch_v10.fragment.html` (`build()`, `scene()`, `genLeaves()`, `SP`, шейдер `barkC` / `potC`).

**Розрахунки (за кодом ескізу, вручну; виміряти харнесом після перенесення):**
- **Ріст**, `L(t)/L` і `R(t)/R_max` при `t` 0 / 0.25 / 0.5 / 0.75 / 1:
  - `L(t)/L` = 0.150 / 0.479 / 0.738 / 0.919 / 1.000;
  - `R(t)/R_max` = 0.100 / 0.283 / 0.506 / 0.746 / 1.000;
  - стрункість Мойоґі 8.9 / 10.0 / 8.6 / 7.3 / 5.9 (саджанець найстрункіший близько `t` 0.25).
- **Темп** при `MatureGrowthDays` 90 і G = 1:
  - гілки з'являються на Д13 / Д24 / Д33 / Д42 / Д50 / Д57 (`t` = 0.14 / 0.26 / 0.37 / 0.47 / 0.56 / 0.64; формула `tOfL(s + 0.05·L)`);
  - купол — Д56–Д83;
  - `H20/H80` = 0.445 / 0.980 ≈ 0.45;
  - при 60 днях — 0.57.
- **Вигини Мойоґі** (`n` 4, `q` 0.835): півхвилі 0.32 / 0.27 / 0.22 / 0.19·(L − s_b), амплітуда 45° / 30° / 20° / 13°.
  - Середній cos за півхвилями (форма tanh, 8 вибірок): 0.807 / 0.914 / 0.962 / 0.983, тож верх осі ≈ 0.907·L (при `n` 5 — 0.92·L).
  - Найбільший кут ≈ 1.07 + 0.035 + d ≈ 65° < 90°.
- **Шакан**: хорда atan(0.28…0.34 / 0.92…0.93) = 17–20° — у межах рішення власника 15–30°.
- **Висота і горщик**:
  - купол-подушка зрілого `b` = 4 + 0.115·290 = 37.4 u (0.129·L), верх листя ≈ 0.97–0.99·L, тобто H Мойоґі ≈ 0.97–0.99·L (Чоккан ≈ 1.07·L);
  - горщик по бортику 2·(140 + 3.5 + 1.4) ≈ 290 u = 1.0·L;
  - отже **H/P ≈ 1.0** (чинні цілі 1.49–1.52).
- **Гілки** (типовий сид `s_1` 0.295, крок 0.15):
  - висоти `s/L` 0.295 / 0.445 / 0.565 (задня) / 0.661 / 0.738 / 0.799 (задня);
  - `Lb/L` 0.370 / 0.321 / 0.199 / 0.239 / 0.208 / 0.132;
  - хорда до горизонталі −8° / +5° / +16° / +23° / +29° / +34°;
  - діапазон 5–8 гілок;
  - найнижча точка гілки 1 на −0.144·`Lb` ≈ 0.22·L над ґрунтом, Pot Lip виконується.
- **Обсяг для моделі**: 6 гілок дають 3·13 + 3·10 + 12 (купол) = 81 вісь, 8 гілок — 104; ліміт 200 вузлів вміщує це при 1–2 вузлах на вісь.
- **Листя** (оцінка для бюджету інстансів):
  - подушка нижньої гілки: Момідзі π·64.4·51.5·0.10 ≈ 1 040, Ямадзакура ≈ 375, Куромацу ≈ 52 щітки × 14 голок;
  - усе дерево: Момідзі ≈ 4 500, Ямадзакура ≈ 2 300, Куромацу ≈ 8 400 голок.
- **72 год при +36 °C** — без змін: §1.8 не чіпає ґрунт і `M_soil`, а вік `t` росте з G (§1.1).
