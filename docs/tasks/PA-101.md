## Технічний план
- Створення проєкту: **відкриваємо корінь репо напряму** з власним `Packages/manifest.json` (Unity генерує відсутні `ProjectSettings/*`). Варіант `-createProject <tmp>` + перенесення відкинуто: шаблон приносить зайві пакети/налаштування, які все одно довелося б вичищати, а копіювання між теками — зайвий ризик для існуючих файлів репо.
- Конфігурація — `Assets/_Project/Editor/ProjectSetup.cs` (`[MenuItem]` + `RunBatch` для `-executeMethod`), ідемпотентно.
- Плейсхолдери: Domain — `IClock`, `IRandomSource`, `Pcg32`; Application — `AppPauseState` (R3); Infrastructure — `SystemClock`; Presentation — порожня збірка (AssemblyInfo); Bootstrap — `RootLifetimeScope`, `AppBootstrapper`.
- Ризики: R3 потребує NuGet-ядра (див. TD-006); `Application` як ім'я namespace конфліктує з `UnityEngine.Application` (TD-008).
