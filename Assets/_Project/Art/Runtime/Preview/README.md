## Контракти JSON

- `pads_<species>.json`: `{"pads":[{"name","x","y","w","h","pivotX","pivotY","size","padPx","innerW","innerH"}]}` — пікселі атласу, `x,y` — лівий верхній кут; `pivotX/pivotY` — частка від лівого **нижнього** кута (точка кріплення до кінчика гілки).
  - **PA-102P — прозоре поле:** кожен рект розширено рівномірно на `padPx` (7–9 px) так, що від листя до краю ректа ≥ 12 px (на mip 1/4 альфа на межі ректа = 0, на 1/8 ≤ 10/255; раніше було до 223 → видимий прямий обріз). Між ректами ще 2 px, пакування — skyline.
  - `innerW×innerH` — старий рект PA-103S, що лежить усередині з відступом `padPx`; pivot = 0.5 / 0.2 **старого** ректа, перерахований у новий (`pivotX` = 0.5, `pivotY` ≈ 0.213–0.23) → фізично та сама точка спрайта.
  - Через поле видиме листя займає `innerW/w` ≈ 0.967 ширини квада → у `TexturedStyleConfig` дефолти покриття/порогів розміру ×1.034. `size` — за `innerW`: L ≥ 540 px, M ≥ 440 px, S < 440 px.
  - Край спрайтів «defringe»: напівпрозорі тексели (0 < α < 250) отримують колір найближчого непрозорого листя ×0.86 (лише темніше за оригінал) — прибрало світло-сіру облямівку (найсильніше була зверху `m0`: 3.6% крайових пікселів → 0%). Темний низ і контур **уже запечені** → `PadUndersideShade` для цих спрайтів = 0 (ADR-0004 §2).
- `pot_tokoname.json`: усі `y` — пікселі **від низу** спрайта, `x` — від лівого краю.
  - `lipY` — верхній край переднього борту (де ґрунт ховається за борт); `innerLeft`/`innerRight` — межі отвору на висоті `lipY`;
  - `innerTopY`, `innerTopLeft`, `innerTopRight` — задній край отвору (лінія ґрунту біля заднього борту);
  - `rimBackTopY` — верх заднього борту. Отвір — чотирикутник між цими точками, альфа 0.
- Ґрунт: малювати **позаду** горщика, центр смуги = `(innerLeft+innerRight)/2`, лінія ґрунту (`groundFromTop`) = `innerTopY` горщика. Стовбур/Небарі — поверх обох.

## Обмеження (чесно)

- Джерело 768×1376: подушки ×2 апскейл → на ретині м'якуваті, дрібні листки читаються як мазки. Ok для стилю, але D5 (2048² на породу) дасть чіткіше.
- Kuromatsu: нічний референс → ключ за відтінком, краї голок місцями рвані, у k3/k4 виїмки знизу (там входили гілки), у 3–4 місцях ледь помітні латки на місці світлячків. Денне перефарбування — апроксимація.
- Yamazakura — повна копія форм momiji з іншим кольором (повтор силуетів між породами).
- Momiji: лише 8 форм (один референс-клен), апекс m0 і m7 мають штучний хвилястий зріз; у низу апексу видно тонкі гілки (залишено — виглядає природно).
- Кора: база апскейлена з ~70 px ширини стовбура → м'яка; уся читабельна деталь процедурна (PA-102P). Тайл 512 → на 3×3 читається ритм із 6 хребтів; сучків більше немає. Скручування — постійний кут у текстурі (не залежить від вигину гілки).
- Горщик: відновлена ділянка заднього борту трохи «смугаста»; на лівій внутрішній стінці лишилась крихта моху.
- Ґрунт — вид «у розрізі» (B3), а не зверху; через отвір читається як мох+гравій. Трапецію маски підігнано лише під `pot_tokoname`.
